# Competitive audit — mushroom apps (2026-07-29)

Sources: App Store / product reviews and public feature pages for Picture Mushroom, Seek by iNaturalist, iNaturalist, Shroomify / Book of Mushrooms class apps.  
Policy for VisionSetil: **copy what works for UX; never copy “safe to eat” claims.**

## What users reward

| Pattern | Apps | VisionSetil action |
|---------|------|--------------------|
| Instant **real field photos** in grids | Seek, iNat, Picture Mushroom | Catalog Wiki/iNat **first** in cascade; no CORS that blanks imgs |
| Multi-angle capture guidance | Power users, forums | Keep multi-vista slots + honesty coach |
| Offline / download packs | Seek, field mycologists | Offline pack surface (study only) |
| Clear risk / toxic warnings | Safety-minded reviewers | Risk chips, never edible green-light |
| Simple primary nav | All top apps | **One** Más control (no double label) |
| Daily engagement loops | Picture Mushroom “games” adjacent | Games hub Setadle / Wordle / Reto |
| History of IDs | Power users | Cuaderno local |

## What users punish

| Pattern | Risk for us |
|---------|-------------|
| False “edible” confidence | Never ship |
| Broken / blank / cartoon photos | Fixed cascade + night placeholders |
| Cluttered double menus | Removed Más duplication |
| Slow ID without feedback | Keep loading stages + multi-view nudge |
| Paywall before any value | Free identify path stays |

## VisionSetil differentiators (keep)

1. Open-set rejection / abstain as a feature  
2. Multi-view critical slots (láminas / perfil / base)  
3. Orientation-only language (legal + safety)  
4. Iberia catalog + cotos map (map UX locked)  
5. Dual **App / Web** shells for store vs browser  

## Residual product bets (from reviews)

1. Faster first paint of heroes on Home / Enciclopedia  
2. Side-by-side lookalike compare (already Lookalike Studio)  
3. Expert / community second opinion (shipped surfaces, grow trust)  
4. Camera multi-view wizard friction still high — simplify coach copy next cycle
